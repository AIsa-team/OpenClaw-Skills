# Creator Marketing

Research creators and plan feasible sponsorship, ambassador and UGC partnerships. Complements kol-creator-discovery with campaign planning and selective candidate research.

Requires Python 3.10+ and `AISA_API_KEY`. Uses Python HTTPS and the AISA Router, with a default $2 task allowance and conversational authorization for additional spend.

See [SKILL.md](SKILL.md) for instructions and the [AISA API reference](https://aisa.one/docs/api-reference) for the catalogue.
